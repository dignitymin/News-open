# News-open

전국 부동산 데일리 브리핑 자동 수집 저장소. 아래 자동화가 매일 이 저장소에 커밋합니다.

이 저장소는 **claude.ai의 예약 루틴(Routine, RemoteTrigger 기반 클라우드 에이전트)** 이 채우고 있습니다.
채팅방이나 루틴이 실수로 삭제되어도, 이 README와 `automation/` 폴더의 프롬프트 파일만 있으면
Claude Code에서 `/schedule` 스킬로 그대로 재구축할 수 있습니다.

이 저장소는 **공개(public)** 입니다. 통합관리시스템 등 외부 시스템이 인증 없이
`https://raw.githubusercontent.com/dignitymin/News-open/main/latest.json` 을 그대로 가져갈 수 있도록
하기 위함입니다. 따라서 이 저장소에는 민감하거나 비공개여야 하는 자료를 절대 넣지 않습니다
(과거 실수로 다른 프로젝트 자료가 잠시 섞였다가 별도 비공개 저장소로 분리된 적이 있음 — 아래 기록 참고).

## 구성

| 경로 | 내용 | 갱신 주기 |
| --- | --- | --- |
| `latest.json` | 전국 부동산 데일리 브리핑 (top 10 뉴스) | 매일 KST 07:00 |

## 재구축 방법 (채팅방/루틴이 다시 사라졌을 때)

1. Claude Code를 열고 이 저장소 URL(`https://github.com/dignitymin/News-open`)만 알려준다.
2. `/schedule` 스킬을 실행해 `automation/daily-realestate-briefing.md`의 내용을 그대로 예약 루틴으로 재생성한다 (매일 KST 07:00).
3. 파일 안의 "cron (UTC)"와 "프롬프트" 내용을 그대로 RemoteTrigger 생성에 사용하면 된다.
4. 생성 후 `claude.ai/code/routines`에서 정상 등록됐는지, 다음 실행 후 이 저장소에 커밋이 올라오는지, 그리고
   `https://raw.githubusercontent.com/dignitymin/News-open/main/latest.json` 이 계속 공개로 열리는지 확인한다.
